How to fix empty links and buttons

Icon-only links (social icons, a hamburger menu, a cart icon) often have no text, so screen readers announce just "link".

  • Add visually hidden text inside the link, or aria-label="Open menu".
  • If the link wraps an image, give the image alt text that names the destination.
  • Remove empty <a> tags left over from page builders.
