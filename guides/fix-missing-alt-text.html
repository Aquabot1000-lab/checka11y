How to fix missing alt text (WCAG 1.1.1)

Screen readers read an image's alt attribute aloud. If it's missing, users may hear the file name, or nothing at all.

Rules of thumb

  • Describe the purpose of the image, not every detail: alt="Technician installing a water heater".
  • Decorative images get an empty alt: alt="". That tells screen readers to skip them.
  • If an image is a link, describe where it goes: alt="Home".
  • Don't start with "image of". Screen readers already announce that it's an image.

Where to edit it

  • WordPress: Media Library → select image → "Alternative Text".
  • Shopify: Products → image → "Add alt text".
  • Wix: click image → Settings → "What's in the image?".
  • Squarespace: image block → Content → filename/alt field.
