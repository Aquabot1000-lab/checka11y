How to fix heading structure

Many screen-reader users jump between headings to skim a page, much like sighted users scan bold titles. Headings chosen for their look instead of their structure break that.

Rules

  • One <h1> per page, describing the page.
  • Don't skip levels going down (h2 → h4). Going back up is fine.
  • Don't use headings just to make text big. Use CSS for that.
  • Don't fake headings with bold paragraphs. Use real heading tags.

How to check

Browser extensions such as HeadingsMap list your page's outline. In page builders, set the heading level in the text block's settings, not by font size.
