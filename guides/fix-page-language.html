How to set the page language (WCAG 3.1.1)

Screen readers use the lang attribute on the tag to choose a pronunciation voice. If it's missing, English text may be read with the wrong accent, or the other way around.

The fix

Use the right code for your content: en, es, fr, en-US. If one section is in another language, mark just that part:

Hola

.

By platform

  • WordPress: Settings → General → Site Language. Most themes output it automatically through language_attributes().
  • Shopify: Most themes use {{ request.locale.iso_code }} in theme.liquid. Check that the tag includes it.
  • Wix / Squarespace: set the site language in the site settings. The platform adds the attribute.
